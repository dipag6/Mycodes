Do they fire the same spikes?

Every simulator receives identical input spikes and connectivity. Rings are the reference implementation's spikes, dots are the simulator's own. With default settings most simulators drift; with five semantic choices aligned, the dots land inside the rings. A dot one 0.1 ms step early still looks centred at this scale, so each panel also counts the spikes that land on exactly the same step.

    Rerun this pilot

    From the snn-benchmark-dashboard folder, in an environment with the five simulators installed:

    python -m pilot.campaign --out runs/my_machine --sizes 500,1000,2000,4000,8000,16000,32000 --reps 5
python -m pilot.export --campaign runs/my_machine

    The campaign resumes after an interruption and stops if the machine changes underneath it.
